## 📌 Architectural Overview

SecurAgent coordinates four tightly coupled subsystems to overcome the limitations of ungrounded LLM hallucination and ensure non-regressive, mathematically certified automated program repair:

1. **Stage 1: Static Pre-Analysis & Invariant Extraction (SlithIR)**:
   - Constructs state variable access control matrices $\mathcal{M}_{\text{access}}: \mathcal{V}_{\text{state}} \times \mathcal{F} \to \{R, W\}$.
   - Performs interprocedural taint flow tracking from user calldata inputs to critical operations (low-level calls, balance adjustments).
   - Synthesizes candidate structural domain invariants ($\Phi_{\text{solvency}}$, $\Phi_{\text{debt}}$, $\Phi_{\text{mutex}}$).

2. **Stage 2: Adversarial Red-Blue Multi-Agent Debate Engine**:
   - **Red-Team Agent (Offensive Exploit Synthesizer)**: Analyzes source code and taint paths to synthesize self-contained, executable Foundry test scripts (`forge-std/Test.sol`).
   - **Blue-Team Agent (Defensive Invariant Verifier)**: Conducts pre-execution cross-examination of exploit preconditions and synthesizes candidate remediation patches $\Delta_{\text{patch}}$.
   - **Arbiter Agent**: Moderates multi-turn interactions, enforcing game termination conditions and passing candidate scripts to concrete execution.

3. **Stage 3: Sandboxed Foundry EVM Execution Grounding Engine**:
   - Executes synthesized PoCs inside an ephemeral EVM state machine (`anvil` / `forge test`) with mainnet state forking at pre-incident blocks ($B_{\text{exploit}} - 1$).
   - Enforces strict prohibition of privileged EVM cheatcodes (`vm.store`, `vm.mockCall`, `vm.prank(owner)`), ensuring asset leakage occurs solely via unprivileged user entrypoints.
   - Computes an independent oracle verdict: $\text{Confirmed} \iff (\text{ExitCode} = 0) \land (\Delta \text{Bal}_{\text{attacker}} > 0 \lor \neg \Phi_{\text{domain}}(\sigma_{\text{post}}))$.

4. **Stage 4: SMT Constrained Horn Clause (CHC) Verification & Certified Repair**:
   - Encodes EVM operational state vector $\mathbf{x} = \langle \mathit{stor}, \mathit{bal}, \mathit{pc}, \mathit{caller}, \mathit{value} \rangle$ into first-order Constrained Horn Clauses (CHCs) evaluated by Z3's $\mu Z$ Spacer engine under $\mathcal{QF\_BV\_ARR}$.
   - Discharges three inductive safety proof obligations:
     $$\text{Init}(\mathbf{x}) \implies \text{Inv}(\mathbf{x})$$
     $$\text{Inv}(\mathbf{x}) \land \text{Tr}(\mathbf{x}, \mathbf{x}') \implies \text{Inv}(\mathbf{x}')$$
     $$\text{Inv}(\mathbf{x}) \land \text{Bad}(\mathbf{x}) \implies \bot$$
   - Executes Counterexample-Guided Abstraction Refinement (CEGAR) to iteratively inject defensive path predicates if counterexamples arise.
   - Enforces non-regression functional equivalence over benign test suites: $\mathcal{O}_{\text{EVM}}(\mathcal{C}^*, \tau) = \mathcal{O}_{\text{EVM}}(\mathcal{C}, \tau)$ for all $\tau \in \mathcal{B}_{\text{benign}}$.

## ⚡ Quickstart & Installation

### 1. Environment Setup
```bash
# Clone the repository
git clone https://github.com/AbdelkaderBerrouachedi/SecurAgent.git
cd SecurAgent

# Create and activate virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

### 2. Run the Full SecurAgent Pipeline
Execute the end-to-end autonomous audit and certified repair pipeline:
```bash
python run_securagent.py
```
